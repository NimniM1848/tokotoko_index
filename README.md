# とことこ指数

気象庁の予報から計算した「おさんぽのしやすさの目安」を、今後約1週間の日ごとに確認できるWebサイトです。

> **これは天気予報ではありません。** 気象庁が発表した予報値をもとに計算した「指数」で、気温や天気などの独自の予想はしていません。出かけるときは、気象庁の最新の情報も確認してください。

## 特徴(予定)

- 全国の府県予報区に対応
- 降水確率、気温、日差し、風から、100点満点でおさんぽのしやすさを計算
- 好み調整スライダー(雨NG度、寒がり度、暑がり度、日差しの影響、風の影響)。設定はブラウザに保存
- 出かけた日の感想を記録して、スライダーを少しずつ調整(予定)
- 夏は、暑さの区分と、指針に沿った注意の文言を表示(予定)

## 仕組み

1. GitHub Actions が、気象庁の予報JSONを1時間ごとに確認します。
2. 発表時刻が変わったときだけ、サイト用のデータに整形します。
3. GitHub Pages が、静的なページとデータを配信します。
4. 指数の計算は、利用者のブラウザで行います。サーバー側で動くプログラムはありません。

## 出典と注意

- 出典: 気象庁ホームページ
- 気象庁の予報値を加工して作成しています。編集責任は、このサイトの作成者にあります。
- 暑さの目安は、公的な指針をもとにした参考情報です。熱中症の危険がある日は、環境省の熱中症予防情報サイトや、熱中症警戒アラートを確認してください。

## 開発状況

画面の初版を作りました(地域選択、7日分の指数、くわしく、好み調整、ダークモード)。感想による自動調整と、設定の引き継ぎも入っています。夏の暑さの区分は、環境省の熱中症予防情報サイトへのリンクだけです。設計の内容は、設計書にまとめています。

## 手元で確かめる

```
python3 -I scripts/build_data.py --out data     # 気象庁のJSONを取得して、data/ に整形する
python3 -m http.server 8000                     # このフォルダで実行し、http://127.0.0.1:8000/ を開く
```

テストは、http://127.0.0.1:8000/tests/ を開くと走ります(Node.js が入っていれば、`node tests/run.js` でも走ります)。
